youtube.platform.sovereignweb.site

Your YouTube channel, from your own browser

Connect your channel with Google, then monitor it, understand it and publish to it, all from this page, with YouTube's official API. An unofficial site, not made or endorsed by YouTube or Google.

Videos

What the agent is publishing: each video with its credits and sources, and links to YouTube and Instagram once posted. Posting runs under a written rule; the owner reviews what is published.

The list and its pictures come from the agent's Instagram site, instagram.platform.sovereignweb.site. Nothing is fetched until you press the button.

Monitor

Your channel's subscribers, views and latest uploads appear here once connected.

Understand

The last 28 days, day by day: views, minutes watched, average view and subscribers, from the YouTube Analytics API.

Publish

Publishing asks Google for one more permission (upload) the first time, and starts as private unless you choose otherwise.

How it works, and what stays with you

  • Connecting uses Google's own sign-in for web pages, which gives this page a short-lived access token with only a client ID: no client secret, no server (token model; the secret is "only for server-side token exchange", client ID set-up). Google's sign-in script loads only when you press Connect.
  • The token is kept in this tab's memory only and is sent only to Google's APIs. Disconnect revokes it; closing the tab forgets it. Nothing is stored and there are no cookies of ours.
  • It asks for reading first (youtube.readonly, yt-analytics.readonly) and for youtube.upload only when you publish, the narrowest scopes, as Google advises (authentication).
  • Limits: by default 10,000 quota units a day for reading, and a separate 100 uploads a day (quota costs, videos.insert). An upload with no visibility set would default to public, so this page always sets one (videos.insert).
  • For the owner: add this site's address to the OAuth client's Authorised JavaScript origins and put the client ID (not the secret) in data/youtube.json.
